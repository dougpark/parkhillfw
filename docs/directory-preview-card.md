# Directory list preview card

- for mobile and desktop
- make a preview card that shows first
- have a button that animates into the current view

# Preview Card
- shows Adults with primary sorted first
- First name, last name, email, mobile phone
- last row show address in a lite font
- has a button/icon/text to "Show more"
- preview card has a shorter vertical height to show more cards per page

# Animate into Full Card
- clicking "Show more" animates the preview card into the full card view
- which replaces the preview card with the full card view
- the full card view shows all details of the household, including all residents and children
- has a button/icon/text to "Show less" to collapse back to the preview card
