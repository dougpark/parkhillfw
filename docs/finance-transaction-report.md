# Admin -> Finance -> Transaction Report
- create a new report


## Transaction Report
### UI
- select date range (defaults to 90 days)
- select product category (defaults to all)
- button to download csv

### Columns:
- Transactiondate
- product category
- product name
- Amount paid
- Fees paid (subtracted from Amount paid)
- Total 
- household-address
- household primary resident name
